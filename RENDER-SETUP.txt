# SPL + WPAY Render setup

1. Put `index-5-updated.html`, `server.js`, and `package.json` in the same GitHub repository. Rename `index-5-updated.html` to `index.html`.
2. Create a Render **Web Service** for the repository. Build command: `npm install`. Start command: `npm start`.
3. Add these Render environment variables:
   - `WPAY_MCH_ID` = `5375`
   - `WPAY_API_SECRET` = your WPAY API Secret (Render only; never put it in HTML)
   - `WPAY_BASE_URL` = `https://api.wpay.life`
   - `PUBLIC_URL` = your deployed HTTPS Render domain, e.g. `https://your-service.onrender.com`
   - `FIREBASE_DATABASE_URL` = your Firebase Realtime Database URL
   - `FIREBASE_SERVICE_ACCOUNT_JSON` = the complete Firebase service-account JSON on one line
4. In WPAY, set the notify/callback URL to `https://YOUR-DOMAIN/api/wpay/notify`.

The browser calls `/api/wpay/collect`; the API secret and request signature stay on the server. Wallet deposits are credited only by a signature-checked WPAY success callback. Withdrawals are stored as pending requests under `withdrawal_requests` and are not automatically paid or debited by this HTML flow.

Important: Protect Firebase Realtime Database with proper security rules. Existing login, referrals, package purchases and client-side earnings in the original HTML still rely on its existing Firebase client logic; production-grade security for those features requires Firebase Authentication and server-side authorization.
